## Why this lab

You want a real front-end CI/CD path on AWS without Terraform deploys or custom DNS for the app under test. <Tooltip term="amplify" label="Amplify Hosting" /> builds from Git. GitHub Actions is the merge gate. Default `*.amplifyapp.com` URLs are enough.

This walkthrough is the guide. The companion sample repo [jajera/amplify-astro-cicd](https://github.com/jajera/amplify-astro-cicd) is what you build (or clone) while following the steps.
