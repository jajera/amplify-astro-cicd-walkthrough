## Delete the Amplify app

1. AWS Console → Amplify → your lab app
2. **App settings** → **General** → **Delete app** (wording may vary)
3. Confirm deletion

This removes:

- `main` and `staging` hosting
- Any remaining <Tooltip term="pr-preview" label="PR preview" /> hosts
- Build history for that app

<Aside type="caution">
<Tooltip term="branch-auto-delete" label="Branch auto-delete" /> only removes preview branches when Git branches disappear. **Deleting the Amplify app** is what ends hosting cost for the lab.
</Aside>

## Optional GitHub cleanup

- Delete feature branches you no longer need
- Keep or delete the `amplify-astro-cicd` repository - your choice
- You can leave the Amplify GitHub App installed for future labs, or remove app access to this repo under GitHub → Settings → Applications
