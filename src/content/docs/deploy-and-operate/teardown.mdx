## Delete the Amplify app

1. AWS Console → Amplify → your lab app (`amplify-astro-cicd`)
2. **App settings** → **General settings**
3. Under **Delete app**, choose **Delete app** → confirm

This removes:

- `main` and `staging` hosting
- Any remaining <Tooltip term="pr-preview" label="PR preview" /> hosts
- Build history for that app

<Aside type="caution">
Amplify <Tooltip term="branch-auto-delete" label="branch auto-disconnection" /> removes Amplify branches when matching Git branches disappear (including previews — and `staging` if Git `staging` was deleted). **Deleting the Amplify app** is what ends hosting cost for the lab.
</Aside>

## Optional GitHub cleanup

- Delete feature branches you no longer need
- Keep or delete the `amplify-astro-cicd` repository - your choice
- You can leave the Amplify GitHub App installed for future labs, or remove app access to this repo under GitHub → Settings → Applications

## Cost reminder

See [Cost](/reference/cost/). A same-day create and delete is typically a negligible Hosting bill if you are not running huge builds.
