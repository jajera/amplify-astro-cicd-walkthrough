<Tooltip term="amplify" label="AWS Amplify Hosting" /> builds and hosts front-end web apps on a CDN. Git-connected continuous deployment is **one** option — this lab uses that path with <Tooltip term="astro" label="Astro" /> (`npm ci` → `astro build` → `dist/`).

## Who owns what

| Concern | Owner in this lab |
| --- | --- |
| Day-to-day deploy | Amplify on Git push / PR |
| Merge quality gate | GitHub Actions + branch protection (<Tooltip term="ci-gate" label="CI gate" />) |
| Creating the Amplify app | You, once, in the Console |

<Aside type="note">
Amplify does **not** wait for your GitHub checks. Protect `staging` and `main` so red CI cannot merge.
</Aside>
