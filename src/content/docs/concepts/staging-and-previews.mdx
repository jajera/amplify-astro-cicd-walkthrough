## Flow

1. Branch → PR **into `staging`** (CI green; Amplify builds a preview)
2. Merge → validate on `https://staging.<app-id>.amplifyapp.com`
3. PR **`staging` → `main`** (same CI gate — protect `staging` with **Restrict deletions** first so auto-delete head branches cannot remove it)
4. Merge → `https://main.<app-id>.amplifyapp.com`

<Aside type="caution">
Do not open feature PRs directly against `main`. Without deletion protection, promoting `staging` → `main` with auto-delete head branches on will delete Git `staging`.
</Aside>

Preview hosts: delete them in the Amplify Console, or enable <Tooltip term="branch-auto-delete" label="automatic branch deletion" /> so Amplify removes them when the Git branch is gone. Neither deletes the Amplify app.
