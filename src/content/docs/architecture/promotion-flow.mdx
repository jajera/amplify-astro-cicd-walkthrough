## End-to-end path

```text
feature branch
    |  PR targeting staging
    |  required GitHub checks (CI gate)
    |  Amplify PR preview URL
    v
staging  -->  https://staging.<app-id>.amplifyapp.com
    |  PR targeting main
    |  same required checks
    v
main     -->  https://main.<app-id>.amplifyapp.com
```

## Responsibilities

| Actor | Role |
| --- | --- |
| Developer | Branch, PR, respond to review |
| GitHub Actions | Lint / tests - <Tooltip term="ci-gate" label="CI gate" /> before merge |
| Branch protection | Blocks merge until checks are green |
| <Tooltip term="amplify" label="Amplify" /> | Builds on push/PR from <Tooltip term="amplify-yml" label="amplify.yml" />; hosts `dist/` |

<Aside type="note">
Amplify and GitHub Actions run in parallel on a push. Protection rules are what stop a red build from reaching `staging` or `main`.
</Aside>
