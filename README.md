# Amplify Astro CI/CD Walkthrough

Guide to deploy Astro to AWS Amplify Hosting with staging, PR previews, the Amplify GitHub App, CI gates, and teardown.

**Site:** https://amplify-astro-cicd-walkthrough.johna.kiwi/

Companion sample app (created by following this guide): [jajera/amplify-astro-cicd](https://github.com/jajera/amplify-astro-cicd).

## Quick start

```bash
npm install
npm run dev
```

Open the local preview URL (usually http://localhost:4321/).

## Structure

```text
src/content/docs/     Walkthrough (Astro Starlight)
public/               Favicon, CNAME, OG image
AGENTS.md             Notes for coding agents
```
